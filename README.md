# 입체도형 탐구 (polyhedron-lab)

중학교 1학년 기초학력 방과후 수업용 입체도형 웹앱입니다. 학생이 패드·휴대폰·PC에서 도형을 손가락으로 돌려 보며 활동합니다.

## 활동
1. **다면체일까?** — 예시와 비예시 살펴보기 → 맞혀 보기 → 다면체의 뜻 만들기 → 도형 20개 분류하기
2. **기둥·뿔·뿔대** — 각뿔을 평행하게/비스듬히 자르기 → 윗면 크기 슬라이더로 각기둥·각뿔대·각뿔 만들기 → 네 칸 분류(18개)
3. **세어 보기** — 이름 짓기 → 면·모서리·꼭짓점 세기, 결과 표

## 사용
`index.html` 하나로 동작합니다. 브라우저에서 바로 열거나 GitHub Pages로 배포해 학생에게 링크를 나눠 주세요.
